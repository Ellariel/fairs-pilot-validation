## A carbon.md example

As a first worked example, we applied FAIR+S to the survey dataset published with this paper and documented the result in a machine- and human-readable *carbon.md* file in the accompanying repository. The file combines FAIR-oriented survey metadata (LimeSurvey instrument, field period, sample) with sustainability attributes for each principle: a bottom-up estimate of energy use and carbon emissions of survey operation and analysis (S1), normalisation per response in the absence of community benchmarks (S2), alignment with the GHG Protocol, ISO 14044, and the Software Carbon Intensity specification (S3), explicit assumptions and responsible parties (S4), and life-cycle information on maintenance, retention, and preservation (S5). The estimate rests on documented assumptions rather than measurements, and the underlying server energy data were not available to us; it is therefore indicative only.
